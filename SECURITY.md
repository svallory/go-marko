# Security Policy

## Supported Versions

Go, Marko! is pre-1.0 and under active development. Security fixes are made
against the latest release on `main` only.

| Version | Supported |
|---------|-----------|
| latest (`main`) | Yes |
| older releases  | No  |

## Reporting a Vulnerability

Please report security vulnerabilities privately — **do not open a public
issue**.

Email **me@saulo.engineer** with a description of the issue, steps to
reproduce, and any relevant details (affected package: Go module or
`marko-go` npm package/CLI).

You can expect an initial response within 48 hours. If the vulnerability is
confirmed, we'll work with you on a fix and coordinated disclosure timeline
before any public announcement.
